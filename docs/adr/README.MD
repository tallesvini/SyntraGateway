# Architecture Decision Records (ADR)

Este diretório contém os **Architecture Decision Records (ADRs)** do projeto Syntra.

Cada ADR documenta uma decisão arquitetural importante tomada durante o desenvolvimento da plataforma, incluindo o contexto, a decisão adotada, suas justificativas e consequências.

## ADRs

| Nº | Título | Status |
|----|--------|--------|

| ADR-0001 | Adoção da Arquitetura Modular Monolith | ✅ Aceito |
| ADR-0002 | Adoção do Domain-Driven Design (DDD) | ✅ Aceito |
| ADR-0003 | Adoção do CQRS | ✅ Aceito |
| ADR-0004 | Adoção da Vertical Slice Architecture | ✅ Aceito |
| ADR-0005 | Persistência com Entity Framework Core | ✅ Aceito |
| ADR-0006 | Estratégia de Multi-Tenancy | ✅ Aceito |
| ADR-0007 | Adoção de API Gateway | ✅ Aceito |
| ADR-0008 | Autenticação com JWT | ✅ Aceito |

## Objetivo

A documentação das decisões arquiteturais permite:

- Registrar o histórico técnico do projeto;
- Facilitar o onboarding de novos colaboradores;
- Justificar escolhas de arquitetura;
- Evitar perda de contexto durante a evolução do sistema;
- Servir como documentação viva da arquitetura do Syntra.

Novas decisões relevantes deverão ser registradas em novos ADRs seguindo a mesma estrutura.
