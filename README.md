# Syntra API Platform

Plataforma corporativa para gerenciamento, segurança, monitoramento, acompanhamento e governança de APIs, desenvolvida com C# e .NET 9.

O projeto foi concebido utilizando os princípios de **Domain-Driven Design (DDD)** e uma arquitetura **Modular Monolith**, promovendo alta coesão entre os módulos, baixo acoplamento e facilidade de evolução do sistema.

## 🎯 Objetivo

Centralizar o gerenciamento e o controle de APIs, fornecendo mecanismos de autenticação, autorização, monitoramento, auditoria e governança para consumidores e provedores de serviços.

## 🏗️ Arquitetura

A solução é estruturada seguindo os princípios de:

- Domain-Driven Design (DDD)
- Modular Monolith
- Clean Architecture
- SOLID
- CQRS
- Separation of Concerns

## 🚀 Tecnologias

- C#
- .NET 9
- ASP.NET Core
- Entity Framework Core
- ReactJs
- PostgreSQL
- FluentValidation
- JWT Authentication
- Swagger / OpenAPI

## ✨ Principais Funcionalidades

- Gerenciamento de clientes e aplicações
- Controle de acesso e autenticação
- Gerenciamento de credenciais
- Rate Limiting
- Auditoria de requisições
- Monitoramento de consumo
- Governança de APIs
- Observabilidade e métricas
- Versionamento de APIs

## 📚 Propósito

Este projeto tem como objetivo servir como referência de arquitetura corporativa moderna utilizando .NET, aplicando boas práticas de design de software, modelagem de domínio e organização modular para construção de sistemas escaláveis e de fácil manutenção.
